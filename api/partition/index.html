    Variance partitioning¶

    What each feature space explains alone and what several explain alike, from the subsets a model or a cohort fits with variance_partition=True. See Models & paradigms for what the flag fits, and Recommendations for how to read the regions and why some come out negative.

    partition ¶

    partition.py — What each feature space explains alone, and what several share.

    Variance partitioning (Lescroart et al., 2015; de Heer et al., 2017) reads the cross-validated R² of a model and of every model with some of its feature spaces left out. A model or a cohort built with variance_partition=True fits those subsets itself, at the λ the full model chose and on its folds (models.TorchTRF); this module turns their R² into regions::

    resolve_spaces(spec, ...)    the spaces a ``variance_partition`` flag names
subset_keys(names)           every non-empty subset, smallest first
venn_regions(scores, names)  each subset's region, by Möbius inversion
shapley_values(regions)      each region split equally among its spaces
VariancePartition            the regions of one model or of a cohort
to_records / from_records    one subject's scores as a record keeps them

    How to read the regions, and why some come out negative, is in docs/recommendations.md.

    VariancePartition dataclass ¶

    VariancePartition(
    spaces: dict[str, list],
    subject_ids: list,
    scores: dict[frozenset, ndarray],
    channels: list | None = None,
)

    The variance partition of one model, or of a cohort subject by subject.

    What variance_partition_ holds on a model or a cohort fitted with variance_partition=True. Frozen, so the fields cannot be reassigned -- shallowly, since the dicts and arrays they hold stay mutable.

    Attributes:

    Name Type Description
    spaces dict of str to list

    {space: [feature, ...]}, in order.
    subject_ids list

    One entry per row of every array below; a single model has one.
    scores dict of frozenset to (n_subjects, n_channels) np.ndarray

    The cross-validated R² of the model with each non-empty subset of the spaces, channel by channel; the full set is the model itself.
    channels list or None

    The channels' names, when known.
    Notes

    Every subset was fitted at the full model's λ on the full model's folds, the variant that recovered the regions best in the benchmark: with a λ per subset, a space that carries nothing inflates the shared regions. Regions are computed per subject from the R² averaged over channels; the figures draw the mean over subjects, which adds up as the regions do.

    plot ¶

    plot(
    kind: str = "venn",
    ax: Axes | None = None,
    title: str | None = None,
    save_path: str | PathLike | None = None,
    show: bool = False,
) -> Figure

    Draw the partition.

    Parameters:

    Name Type Description Default
    kind (venn, upset, shapley)

    "venn": circles whose regions have the areas of the regions, for up to three spaces. "upset": one bar per region with the spaces it belongs to marked below, for any number. "shapley": one bar per space, its Shapley share.

    		 "venn"
    ax Axes

    Where to draw a Venn diagram or the Shapley bars; None makes a figure. An UpSet plot always makes its own.

    		 None
    title str

    Overrides the default, which states the full model's R².

    		 None
    save_path (str, PathLike or None)

    Where to write the figure; parent directories are created.

    		 None
    show bool

    Display the figure instead of closing it in pyplot.

    		 False

    Returns:

    Type Description
    Figure

    Raises:

    Type Description
    ValueError

    On an unknown kind, or a Venn diagram of more than three spaces.
    Notes

    A region's area is the absolute value of its mean over subjects, so a negative region -- the full model gains less than the parts suggest, see docs/recommendations.md -- is drawn hatched, with a dashed outline, and labelled with its sign. Three circles cannot give seven regions any areas at all, so their layout is fitted and the figure states how far it is off when that is more than 5 %.

    venn_regions ¶

    venn_regions(
    scores: dict[frozenset, ndarray], names: list[str]
) -> dict[frozenset, ndarray]

    Each subset's region, from the R² of every subset's model.

    Parameters:

    Name Type Description Default
    scores dict of frozenset to np.ndarray

    R(S), the R² of the model with the spaces in S, for every non-empty S; any shape, the same for every key.

    		 required
    names list of str

    The spaces.

    		 required

    Returns:

    Type Description
    dict of frozenset to np.ndarray

    g(T) for every non-empty T: what the spaces in T explain together and no other space does.
    Notes

    With F every space and R(∅) = 0, removing the spaces V loses G(V) = R(F) - R(F ∖ V), the regions that touch V. Möbius inversion gives each region::

    g(T) = Σ_{V ⊆ T} (-1)^(|T| - |V|) G(V)

    A singleton's region is that space's own, R(F) - R(F ∖ {i}); with two spaces the shared region is R(A) + R(B) - R(AB). The regions add up to R(F).

    shapley_values ¶

    shapley_values(
    regions: dict[frozenset, ndarray], names: list[str]
) -> dict[str, ndarray]

    Each space's share of the full model's R².

    Every region is split equally among the spaces it belongs to.

    Parameters:

    Name Type Description Default
    regions dict of frozenset to np.ndarray

    From venn_regions.

    		 required
    names list of str

    The spaces.

    		 required

    Returns:

    Type Description
    dict of str to np.ndarray

    {space: share}; the shares add up to the full model's R².
    Notes

    This is the Shapley value of each space in the game whose payoff is the R² of a set of spaces -- in regression, the LMG decomposition (Lindeman, Merenda and Gold, 1980): each space's gain, averaged over every order in which the spaces could be added.
