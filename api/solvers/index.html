    Solvers¶

    Penalty matrices and the penalized solve. See the concept page.

    solvers ¶

    Penalty matrices and the regularized linear solve for TRF models.

    Every regularized TRF solver builds a penalty matrix M and solves the normal equations (X^T X + λ M) coef = X^T y. This module owns three concerns so the model classes in models.py stay thin.

    Penalty construction. Each penalty is a pure function of the design shape (n_subfeatures, n_delays) -- no dependence on the stimulus data -- registered by name in the :data:PENALTIES registry with the register decorator. Adding a penalty is writing the function and decorating it; nothing else needs editing.

    ridge            : Tikhonov regularization (``M = I``).
ridge-laplacian  : temporal Laplacian smoothness penalty. It penalizes
                   differences between adjacent lags, not the kernel's
                   size, so it smooths without shrinking.

    cross_corr is not a registered penalty: it has no M (unregularized cross-correlation baseline) and is the penalty is None case of solve_penalized.

    The solve. solve_penalized is the one entry point, and picks among three strategies: one eigendecomposition reused across every scale sharing a ratio, one batched LU over the stacked grid, or one factorization per λ. The first needs a diagonal penalty, the second enough VRAM, and the third always works -- which is why it is where the other two fall back. Which of them wins is partly a hardware question, and the sweep behind the numbers is recorded in development/measured-constants.md, which ships with the source rather than with this documentation.

    A caller states the problem and never the method: nothing outside this module chooses a strategy, or needs to know there is more than one.

    Banded ridge

    In a banded ridge the design's columns are partitioned into bands -- groups of features sharing one regularization strength -- so regularization is a vector, one entry per band, instead of a scalar. This module never sees bands: models expands a per-band λ into one weight per design column before calling, and search decides which vectors to try. What arrives here is always per-column weights, and an ordinary scalar ridge is just the case where every column carries the same weight -- one row of scales either way.

    Vocabulary

    regularization One regularization strength to solve at. A scalar for an ordinary ridge, a vector with one entry per band for a banded one -- n_values counts either kind, and both arrive here as one row of the (n_values, n_columns) scales matrix. scale, ratio A vector λ factored as λ = scale * ratio, with scale the global strength (lambda) and ratio the relative weighting between bands. Rows sharing a ratio are what the eigendecomposition path serves in one factorization; _ratio_groups recovers them, and search generates them that way to begin with.

    Scope

    Everything here is per block -- one selected feature (or interaction) with its own delay window. The model's full penalty is the block diagonal of these, assembled in models._build_block_penalty, so n_columns in this module is one block's width and models sums it over blocks. Axis names follow the package glossary in docs/concepts/notation.md.

    register ¶

    register(
    name: str, *, is_diagonal: bool
) -> Callable[[PenaltyBuilder], PenaltyBuilder]

    Register a penalty-matrix builder under name in :data:PENALTIES.

    Parameters:

    Name Type Description Default
    name str

    Solver name the penalty is built for, as passed to build_penalty.

    		 required
    is_diagonal bool

    Whether M is diagonal, which is what lets the regularizer fold into a rescaling of the design so a whole sweep of scales comes out of one eigendecomposition. Declared rather than detected: the property belongs to the penalty's definition, and testing a built matrix for it would cost a full pass over every entry.

    		 required

    Returns:

    Type Description
    Callable[[PenaltyBuilder], PenaltyBuilder]

    Decorator returning the function unchanged.
    Notes

    The decorated function must accept (n_subfeatures, n_delays, *, device, dtype) and return the square M of size n_subfeatures * n_delays. That size is derived from the two arguments rather than passed, so a caller cannot state a width that contradicts the shape it just described.

    laplacian_penalty ¶

    laplacian_penalty(
    n_subfeatures: int,
    n_delays: int,
    *,
    device: device,
    dtype: dtype
) -> Tensor

    Temporal Laplacian penalty, for delay-first column ordering.

    Parameters:

    Name Type Description Default
    n_subfeatures int

    Raw stimulus columns of the block, before lagging.

    		 required
    n_delays int

    Lags in the block's window.

    		 required
    device (device, dtype)

    Where and at what precision to build the matrix.

    		 required
    dtype (device, dtype)

    Where and at what precision to build the matrix.

    		 required

    Returns:

    Type Description
    Tensor

    (n_columns, n_columns) Laplacian, with n_columns = n_subfeatures * n_delays.
    Notes

    Adjacent delays of the same subfeature sit n_subfeatures apart in the flat coefficient vector, so the off-diagonals land at +/- n_subfeatures. The first and last delay have one temporal neighbour instead of two, hence a main diagonal of 1 there and 2 elsewhere.

    Equivalently M = L_{n_delays} (x) I_{n_subfeatures}: the 1-D Laplacian over the delays, replicated per subfeature.

    w^T M w = sum_d (w[d+1] - w[d])**2, a first-difference penalty: a constant kernel costs nothing and a slowly varying one very little. Ridge protects a weak predictor by pulling its kernel towards zero; this penalty does not, so slow noise -- where 1/f noise such as EEG's has its power -- can enter such a predictor as a large, smooth kernel.

    solve_penalized ¶

    solve_penalized(
    XTX: Tensor | None,
    XTY: Tensor,
    penalty: Tensor | None,
    regularization: RegularizationLike,
    *,
    device: device,
    dtype: dtype,
    grid_batch_cap_bytes: int,
    penalty_is_diagonal: bool = False,
    solver_name: str | None = None,
    verbose: int | None = None
) -> Tensor | list[Tensor]

    Solve (XTX + λ * penalty) coef = XTY from precomputed Grams.

    The one entry point to the numeric solve. It picks among three strategies -- _eigendecomposition_solve, _batched_solve and _sequential_solve -- so a caller states the problem and never the method.

    Parameters:

    Name Type Description Default
    XTX Tensor or None

    Symmetric, per-sample-averaged (n_columns, n_columns) normal matrix (X^T X / n). May be None only when penalty is None.

    		 required
    XTY Tensor

    Per-sample-averaged (n_columns, n_channels) cross-moment matrix (X^T y / n).

    		 required
    penalty Tensor or None

    (n_columns, n_columns) penalty M, which must already be symmetric: it is taken on trust rather than re-symmetrized, which would cost two full (n_columns, n_columns) temporaries per call. Use build_penalty, which guarantees it. None selects the unregularized cross_corr baseline.

    		 required
    regularization RegularizationLike

    One regularization strength, a 1-D grid to sweep, or a 2-D (n_values, n_columns) array of per-column weights -- the banded case. See expand_scales for how the three are told apart.

    		 required
    device (device, dtype)

    Compute device and precision.

    		 required
    dtype (device, dtype)

    Compute device and precision.

    		 required
    grid_batch_cap_bytes int

    Ceiling on the batched workspace. See _grid_fits_one_batch.

    		 required
    penalty_is_diagonal bool

    Whether penalty is diagonal, which unlocks the eigendecomposition path. Declared by the caller from penalty_is_diagonal, not inspected here: testing the matrix would cost a full pass over it, and the answer is a property of the penalty's definition.

    		 False
    solver_name str or None

    Only used to label the singular-matrix warning messages.

    		 None
    verbose int or None

    The calling model's resolved verbosity level, overriding the global one for the messages this solve emits. None follows the global setting.

    		 None

    Returns:

    Type Description
    torch.Tensor or list of torch.Tensor

    (n_columns, n_channels) coefficients for a scalar regularization, or one such tensor per λ when sweeping.
