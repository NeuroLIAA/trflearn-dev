    Statistics¶

    Pure, stateless helpers consumed by TRFGroup and usable standalone.

    statistics ¶

    statistics.py — Group-level statistics for TRF kernels.

    Pure, stateless helpers consumed by group.TRFGroup and usable standalone. Nothing here holds class state or imports models/core, so the dependency graph stays acyclic: the classes import this module, never the reverse.

    Four groups of function:

    Descriptives. grand_average averages per-subject kernels across a cohort; descriptive_summary counts the cohort and summarizes its metrics, its selected regularization, and -- when it was fitted with diagnostics=True -- how the collinearity of the design varies between subjects.

    The paired test. paired_signed_rank is the Wilcoxon signed-rank test of per-subject differences against zero, behind group.TRFGroup.compare_to.

    The cluster test. cluster_1samp runs a one-sample permutation test against zero in either of its two flavours, cluster mass at a fixed t threshold or TFCE; tfce_1samp is the TFCE flavour under its own name, and t_threshold turns a p into the t the other flavour needs. delay_positions and restore_full_delays restrict a test to a window of delays and put the result back on the whole axis. mne is imported lazily, so the rest of the module carries no hard MNE dependency. The permutation loop is the one place in the package worth a progress bar.

    Spatial adjacency, which the cluster test needs when the channels are source parcels rather than sensors and mne.channels.find_ch_adjacency therefore has no montage to read. source_adjacency builds the graph from centroid proximity, surface_adjacency from shared borders on the cortex.

    Axis names follow the package glossary in docs/concepts/notation.md.

    paired_signed_rank ¶

    paired_signed_rank(delta: ndarray) -> tuple[float, float]

    Wilcoxon signed-rank test of per-subject differences against zero.

    Parameters:

    Name Type Description Default
    delta ndarray

    (n_subjects,) paired differences.

    		 required

    Returns:

    Type Description
    tuple of float

    (statistic, p), both nan when the test cannot say anything.

    Warns:

    Type Description
    UserWarning

    With fewer than MIN_SIGNED_RANK_SUBJECTS subjects, or when every difference is exactly zero -- identical fits, which scipy refuses rather than calling a tie.
    Notes

    The group-level statistic behind group.TRFGroup.compare_to, which pairs two cohorts subject by subject. Signed-rank rather than a t-test because a per-subject difference of information criteria has no reason to be normally distributed: one subject with a badly conditioned design produces an outlier of arbitrary size, which is exactly what a rank test is indifferent to and a t-test is not.

    source_adjacency ¶

    source_adjacency(
    positions: ndarray,
    n_neighbors: int = 6,
    dist_factor: float = 1.5,
) -> csr_matrix

    Neighbourhood graph of source-space regions from their centroid positions.

    The sensor-space counterpart of this is mne.channels.find_ch_adjacency, which needs a montage and so cannot describe parcels. Here proximity stands in for anatomy: two regions are neighbours when their centroids are close, which is what lets a cluster test group a spatially contiguous effect instead of treating every region as independent.

    Two rules are unioned, because either alone fails at one end of the range. A distance threshold (dist_factor x the median nearest-neighbour distance) captures genuine local structure but leaves outlying regions with no neighbours at all; a k-nearest floor (n_neighbors) guarantees every region is connected but, alone, would link distant regions in sparse areas.

    Parameters:

    Name Type Description Default
    positions np.ndarray of shape (n_regions, 3)

    Centroid coordinates, in the order of the data's channels. Typically read off an mne.Info built by core.TRFData.set_source_positions.

    		 required
    n_neighbors int

    Nearest-neighbour floor: how many neighbours every region gets even when the distance threshold would leave it isolated.

    		 6
    dist_factor float

    Distance threshold, as a multiple of the median nearest-neighbour distance. Larger values give larger, more permissive clusters.

    		 1.5

    Returns:

    Type Description
    csr_matrix

    (n_regions, n_regions) boolean adjacency, symmetric and including the diagonal -- the form mne.stats.combine_adjacency expects.

    Raises:

    Type Description
    ValueError

    If positions is not (n_regions, 3), holds a non-finite coordinate, or if either knob is out of range.
    Notes

    The graph is geometric, not anatomical: it does not know about the cortical surface, so two regions facing each other across a sulcus (or across the midline) count as neighbours if their centroids are close.

    surface_adjacency ¶

    surface_adjacency(
    ch_names: Sequence[str],
    labels: Sequence,
    surfaces: dict[str, tuple],
) -> csr_matrix

    Neighbourhood graph of cortical regions from their borders on the surface.

    The anatomical alternative to source_adjacency. Proximity is a proxy for adjacency and a leaky one: centroids that are close in space may sit on opposite banks of a sulcus, or on opposite sides of the midline, and a cluster is then free to jump a gap it should not cross. Here two regions are neighbours only when an edge of the surface triangulation actually joins a vertex of one to a vertex of the other -- they share a border.

    Hemispheres are never linked, since no edge crosses between them.

    The surfaces and labels are passed in rather than read here, so this package keeps no knowledge of FreeSurfer layouts and the graph can be built for any parcellation the caller can load::

    labels = mne.read_labels_from_annot(subject, parc, subjects_dir)
surfaces = {
    h: mne.read_surface(f"{subjects_dir}/{subject}/surf/{h}.white")
    for h in ("lh", "rh")
}

    Parameters:

    Name Type Description Default
    ch_names sequence of str

    Region names, in the order of the data's channels. Names carrying MNE's -0/-1 uniqueness suffixes are matched on their base name, and several channels may share one label -- centroids of the same parcel are then joined to each other as well.

    		 required
    labels sequence of mne.Label

    The parcellation. Each needs name, hemi and vertices.

    		 required
    surfaces dict of str to tuple

    {hemi: (rr, tris)} as returned by mne.read_surface, keyed by "lh"/"rh". Only tris and the vertex count are used, so the surface may be any of white/pial/inflated -- they share a topology.

    		 required

    Returns:

    Type Description
    csr_matrix

    (n_regions, n_regions) boolean adjacency, symmetric and including the diagonal.

    Raises:

    Type Description
    ValueError

    If no label name matches a channel, which means the parcellation and the data describe different things.
    See Also

    source_adjacency : the proximity-based graph, which needs no anatomy.

    Notes

    A region whose label borders nothing in ch_names keeps only its diagonal and so sits out every spatial cluster. Unlike source_adjacency, which forces a k-nearest floor, nothing is invented here: no border, no link.

    map_adjacency ¶

    map_adjacency(
    map_shape: tuple[int, ...],
    info: Info | None,
    spatial_adjacency: csr_matrix | None = None,
    source_kwargs: dict | None = None,
) -> csr_matrix

    The adjacency of a cluster map over lattice dimensions and channels.

    map_shape is a map's shape without its subject axis -- the lattice dimensions (delays, sub-features), channels last. The lattice dimensions become regular lattices; the channels' graph is, in order of precedence:

    • spatial_adjacency, as given;
    • the montage adjacency of info, for sensors;
    • for source-space targets (parcels, virtual electrodes), which have no montage, source_adjacency over the region centroids core.TRFData.set_source_positions stored in info;
    • failing all of them, independent channels, with a warning.

    Parameters:

    Name Type Description Default
    map_shape tuple of int

    (*lattice_dims, n_channels).

    		 required
    info Info or None

    The map's channels, in its order.

    		 required
    spatial_adjacency csr_matrix or None

    (n_channels, n_channels), overriding info.

    		 None
    source_kwargs dict or None

    Forwarded to source_adjacency.

    		 None

    Returns:

    Type Description
    csr_matrix

    Over prod(map_shape) locations.

    Raises:

    Type Description
    ValueError

    If spatial_adjacency is not square over the channels, or the channels mix types.

    t_threshold ¶

    t_threshold(p: float, df: int, tail: int = 0) -> float

    Cluster-forming t threshold: the t value cutting off p at df dof.

    The cluster-mass flavour of cluster_1samp needs a t value, not a p value, to decide which points enter a candidate cluster. This converts the p one actually has in mind (0.01 is a common choice, stricter than the 0.05 used to judge the resulting clusters) into that t.

    Parameters:

    Name Type Description Default
    p float

    Point-wise probability the threshold should cut off.

    		 required
    df int

    Degrees of freedom -- n_subjects - 1 for a one-sample test.

    		 required
    tail int

    0 = two-sided (the p is split between the tails), +/-1 = one-sided.

    		 0

    Returns:

    Type Description
    float

    The (positive) t threshold.

    Raises:

    Type Description
    ValueError

    If p is outside (0, 1) or df is below 1.

    Examples:

    >>> t_threshold(0.01, df=19)          # 20 subjects, two-sided
2.860...

    restore_full_delays ¶

    restore_full_delays(
    t_obs: ndarray,
    pvals: ndarray,
    positions: ndarray,
    n_delays: int,
) -> tuple[ndarray, ndarray]

    Scatter a windowed test result back onto the full delay axis.

    Untested delays get pvals = 1.0 -- the same "no evidence here" the cluster-mass flavour already uses for points outside every cluster -- and t_obs = NaN, which reads as "not tested" rather than as a t of zero. Keeping the full length is what lets the plots, whose time axis is the kernel's, shade a windowed result without knowing one was run.

    		 required
    n_delays int

    Length of the full axis.

    		 required

    cluster_1samp ¶

    cluster_1samp(
    data: ndarray,
    adjacency: csr_matrix | None = None,
    threshold: float | dict | None = None,
    n_permutations: int = 1024,
    tail: int = 0,
    seed: int | None = None,
    n_jobs: int = 1,
    progress: bool | None = None,
    verbose: int | None = None,
) -> tuple[ndarray, ndarray]

    One-sample cluster permutation test against zero, wrapping mne.stats.

    Both flavours of the test are here, chosen by threshold, because they differ only in that argument and in how the p-values map back onto the grid:

    • threshold=float -- cluster mass. Points whose t exceeds the threshold are grouped into clusters and each cluster's summed t is compared against the permutation null of the largest cluster. The result is one p-value per cluster; every point in a cluster shares it. Cluster inference does not localize: the honest statement is "this cluster is significant", not "this delay/channel is". Use t_threshold to pick the float.
    • threshold=dict (or None -> dict(start=0, step=0.2)) -- threshold-free cluster enhancement, which integrates over every threshold and yields a genuine per-point p-value, so no cluster-forming threshold has to be guessed.

    mne.stats.spatio_temporal_cluster_1samp_test accepts data of shape (n_observations, p[, q], n_vertices), so a multi-column feature is handled natively -- no need to collapse its sub-features.

    Parameters:

    Name Type Description Default
    data ndarray or Tensor

    Per-subject kernel maps, shaped (n_subjects, n_delays, n_channels) or (n_subjects, n_delays, n_subfeatures, n_channels). Channels (the dimension the adjacency describes) must be last; the middle dimensions form regular lattices.

    		 required
    adjacency csr_matrix or None

    The full adjacency over prod(data.shape[1:]) locations, as built by mne.stats.combine_adjacency (lattice over the middle dims x channel adjacency). None lets MNE assume a lattice along the last dimension only, which is valid only for the 3D case with lattice channels.

    		 None
    threshold (float, dict or None)

    Cluster-forming t threshold (cluster mass), TFCE parameters (dict), or None for the default TFCE settings.

    		 None
    n_permutations int

    Sign-flip permutations for the null.

    		 1024
    tail int

    0 = two-sided, 1 = positive, -1 = negative.

    		 0
    seed int or None

    RNG seed for reproducibility.

    		 None
    n_jobs int

    Parallel jobs for the permutation loop, forwarded to mne.stats. The loop is the whole cost of the test -- at a few thousand permutations over a channels x lags grid this is the difference between seconds and minutes -- so raise it on a multi-core machine.

    		 1
    progress bool or None

    Show MNE's permutation progress bar. None follows the verbosity level and shows it at DEBUG; True/False decides for this call alone, which is how a quiet cohort run still gets a bar on the one test that takes minutes. MNE gates the bar on its own log level, so showing it also prints MNE's four setup lines -- the two cannot be separated.

    		 None
    verbose int or None

    A resolved verbosity level overriding the global one when progress is left at None. See trflearn.verbosity.

    		 None

    Returns:

    Name Type Description
    t_obs ndarray

    The t statistic, shaped data.shape[1:], TFCE-enhanced in the TFCE flavour.
    pvals ndarray

    The same shape: a per-point p-value under TFCE, and under cluster mass the p-value of the cluster each point belongs to (1.0 where a point joined no cluster). Thresholding it therefore recovers the significant-cluster mask in either flavour.

    Raises:

    Type Description
    ValueError

    If data is neither 3-D nor 4-D.

    		 required
    adjacency ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    n_permutations ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    tail ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    seed ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    n_jobs ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    progress ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required
    verbose ndarray

    As in cluster_1samp, forwarded unchanged.

    		 required

    Returns:

    Type Description

    Raises:

    Type Description
