    Preprocessing¶

    Per-column normalizers with a shared fit_train / fit_test / inverse_transform interface, plus the lagging helper. See the concept page.

    Standardize¶

    Standardize ¶

    Standardize(
    axis: int = 0,
    precision: str = "float32",
    by_gpu: bool = False,
)

    Bases: _Scaler

    Z-score train and test data for a linear regressor.

    Learns a per-axis mean and (biased) standard deviation on the training data and reuses them for the test data, so the test statistics never leak into the fit. See _Scaler for the shared contract.

    Attributes:

    Name Type Description
    mean, std Tensor

    Learned on the training data, shaped like the input with axis reduced to length 1 (keepdim=True). std is the biased estimator (unbiased=False), for consistency with NumPy's default.

    Examples using Standardize

    • 1 · Simulation
    • 1 · OPM sensor TRF
    • 2 · Natural speech TRF
    • 3 · OPM source TRF

    scale property ¶

    scale: Tensor

    std + 1e-12, the divisor of the transform.

    fit ¶

    fit(data: ArrayOrTensor) -> Standardize

    Learn mean/std from data without transforming it.

    inverse_transform ¶

    inverse_transform(data: ArrayOrTensor) -> Tensor

    Map standardized data back to the original scale.

    Parameters:

    Name Type Description Default
    data ndarray or Tensor

    Standardized values.

    		 required

    Returns:

    Type Description
    Tensor

    data * (std + 1e-12) + mean, with the train statistics.

    Normalize¶

    Normalize ¶

    Normalize(
    axis: int = 0,
    precision: str = "float32",
    by_gpu: bool = False,
)

    Bases: _Scaler

    Min-max scale train and test data to [0, 1] for a linear regressor.

    Learns the per-axis minimum and range on the training data and reuses them for the test data. See _Scaler for the shared contract.

    Attributes:

    Name Type Description
    min, max Tensor

    Minimum and maximum of the training data, shaped like the input with axis reduced to length 1 (keepdim=True).
    range Tensor

    max - min, the divisor the transform actually uses.

    scale property ¶

    scale: Tensor

    range + 1e-12, the divisor of the transform.

    fit ¶

    fit(data: ArrayOrTensor) -> Normalize

    Learn min/max/range without transforming data.

    inverse_transform ¶

    inverse_transform(data: ArrayOrTensor) -> Tensor

    Map normalized data back to the original scale.

    Parameters:

    Name Type Description Default
    data ndarray or Tensor

    Values in [0, 1].

    		 required

    Returns:

    Type Description
    Tensor

    data * (range + 1e-12) + min, with the train statistics.

    Identity¶

    Identity ¶

    Identity(
    axis: int = 0,
    precision: str = "float32",
    by_gpu: bool = False,
)

    Bases: _Scaler

    No-op scaler (preprocess=None): only moves data to device and dtype.

    Implements the same interface as Standardize and Normalize (see _Scaler), so the fit/predict paths can stay preprocessing-agnostic. Nothing is learned and inverse_transform is the identity, but the returned tensor is still owned by the caller like the other two.

    scale property ¶

    scale: None

    Nothing is divided.

    fit ¶

    fit(data: ArrayOrTensor) -> Identity

    Learn nothing; return self.

    inverse_transform ¶

    inverse_transform(data: ArrayOrTensor) -> Tensor

    Return data on this scaler's device and dtype, unchanged.

    shifted_matrix(
    features: ArrayOrTensor,
    delays: Indices,
    indices_to_keep: Indices | None = None,
    default_chunk_size: int = 32,
    use_gpu: bool = True,
    precision: str = "float32",
    output_torch: bool = True,
    train_indexes: Indices | None = None,
    pred_indexes: Indices | None = None,
    verbose: int | None = None,
) -> ArrayOrTensor | tuple[ArrayOrTensor, ArrayOrTensor]

    Build a time-shifted design matrix for given features and delays.

    Columns are ordered delay-first: every feature for delays[0], then every feature for delays[1], and so on.

    Parameters:

    Name Type Description Default
    features ndarray or Tensor

    Input features of shape (n_samples, n_subfeatures).

    		 required
    delays list of int or np.ndarray or torch.Tensor

    Delays to apply to the features.

    		 required
    indices_to_keep list of int or np.ndarray or torch.Tensor

    Sample positions to build rows for. None keeps every sample.

    		 None
    default_chunk_size int

    Delays gathered at once when the full gather would not fit in memory.

    		 32
    use_gpu bool

    Attempt GPU processing when one is available.

    		 True
    precision str

    'float16', 'float32' or 'float64'.

    		 'float32'
    output_torch bool

    Return a torch tensor rather than a NumPy array.

    		 True
    train_indexes list of int or np.ndarray or torch.Tensor

    Optional rows to split the result into. Both must be given for the split to happen.

    		 None
    pred_indexes list of int or np.ndarray or torch.Tensor

    Optional rows to split the result into. Both must be given for the split to happen.

    		 None
    verbose int or None

    The calling model's resolved verbosity level, overriding the global one for the CUDA-retry message. None follows the global setting.

    		 None

    Returns:

    Type Description
    ndarray or Tensor or tuple

    The design matrix, shaped (n_kept_samples, n_delays * n_subfeatures). With train_indexes and pred_indexes both given, its two row subsets instead.

    Raises:

    Type Description
    ValueError

    If features is not 2D, or precision names no supported dtype.
    RuntimeError

    If every candidate device failed.
    Notes

    A CUDA failure is retried on CPU whatever its cause, so the warning names the error rather than assuming it was an allocation.
