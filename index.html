    TRFlearn¶

    Temporal Response Function estimation in PyTorch — regularized lagged linear models between continuous stimuli and neural responses (MEG/EEG), on CPU or GPU, with named features, per-feature time windows, segment-aware cross-validation, MNE-native I/O and cohort-level statistics.

    Get started API reference Tutorials

    pip install -e .  ·  CPU / CUDA  ·  MNE Raw  ·  grand average + TFCE

    Why TRFlearn¶

    • PyTorch core

      Regularized normal equations (XᵀX + λ·M)·TRF = Xᵀy solved on CPU or GPU. Ridge, temporal Laplacian, or an unregularized cross-correlation baseline.

    • Named features & interactions

      Select features by name, add interactions (outer products), give each its own delay window, and expand amplitudes with spline bases — all in one spec.

    • Three CV paradigms

      pooled k-fold, Crosse–Lalor averaged leave-one-out, or a simple train_test split — one factory, TRFModel(cv=...), same call surface.

    • MNE-native

      Feed mne.Raw targets, keep the montage, and export kernels as Evoked for the full MNE plotting toolbox.

    • Cohort analysis

      TRFGroup fits one spec across subjects, then grand-averages and runs threshold-free cluster enhancement (TFCE) over delay × sub-feature × channel.

    • Plotting built in

      On-demand figures at the model, subject and cohort level: butterfly + mean/std, TFCE shading, and mne.Evoked passthroughs — see Plotting.

    60-second example¶

    import numpy as np
from trflearn import TRFData, TRFModel

# Toy data: 2 minutes at 128 Hz, one stimulus feature, 8 EEG channels whose
# response is the stimulus filtered by a known kernel, plus noise.
rng = np.random.default_rng(0)
envelope = rng.standard_normal((128 * 120, 1))
true_trf = np.sin(np.linspace(0, 2 * np.pi, 40))
response = np.convolve(envelope[:, 0], true_trf)[: len(envelope), None]
eeg = response + 5 * rng.standard_normal((len(envelope), 8))

data = TRFData(features={"envelope": envelope}, y=eeg, sample_rate=128)
data.create_partitions()   # 5 contiguous folds
model = TRFModel(
    TRFDataset=data, features=["envelope"], default_window=(-0.1, 0.5)
)
best_regularization, (trfs, r2) = model.gridsearchCV(validation_plot=False)
model.plot_average("envelope")
