    Plotting¶

    Figures are on-demand methods, not side-effects. A shared base class (TRFPlots) gives models, cohorts and single subjects one plotting API, so the same call works on all three:

    model.plot_joint("envelope")           # a fitted model
group.plot_average("envelope")         # the cohort grand-average
group("s01").plot_image("envelope")    # one subject, via group(subject_id)

    Every method returns the figure (or a list of them) and closes it in pyplot, so it stays usable afterwards; save_path= writes it (creating parent directories) and show=True displays it.

    The whole surface at a glance¶

    Method Takes Model Cohort Subject Montage Notes
    plot spec ✓ ✓ ✓ optional butterfly via mne.Evoked.plot
    plot_joint spec ✓ ✓ ✓ required butterfly + topomaps at the peaks
    plot_image spec ✓ ✓ ✓ optional channels × time heatmap
    plot_psd spec ✓ ✓ ✓ optional spectrum of the kernel
    plot_psd_topomap spec ✓ ✓ ✓ required spectrum as topomaps
    plot_average spec ✓ ✓ ✓ optional butterfly + channel mean/std, drawn by the package
    plot_contrast spec_a, spec_b ✓ ✓ ✓ optional¹ the difference of two features
    plot_features specs=None ✓ ✓ ✓ required one summary column per feature
    plot_feature spec ✓ ✓ ✓ required that column, alone
    plot_metric_topomap — ✓ ✓ ✓ required held-out score per channel
    plot_source_butterfly spec ✓ ✓ ✓ centroids source-space butterfly, coloured by position
    to_stc spec, labels, src ✓ ✓ ✓ centroids a SourceEstimate for 3D rendering
    plot_bootstrap — ✗ ✓ ✗ no per-subject metric distributions
    validation_plot — ✓ ✗ ✗ no the gridsearchCV figure

    ¹ plot_contrast(..., kind="joint") does require one.

    spec is a feature name ("envelope"), or a tuple for an interaction (("envelope", "onsets")) — written exactly as in features.

    Two settings, not methods, read by every figure of that object:

    model.plot_baseline = (None, 0)        # display-only baseline, MNE convention
model.plot_baseline = {"saccade": (None, 0)}     # or per feature
group.plot_sphere = 0.095              # fixed head size for every topomap

    plot_baseline corrects a copy on the way to the plot — coef_ is never touched. plot_sphere pins the head geometry so sensors do not shift between subjects when MNE refits it per recording.

    mne.Evoked passthroughs¶

    plot, plot_joint, plot_image, plot_psd, plot_psd_topomap build the kernel's Evoked for a feature and delegate to the identically-named mne.Evoked method (extra **kwargs forwarded), so the full MNE toolbox is available.

    What they need depends on whether they draw a head:

    • plot, plot_image and plot_psd need no montage, nor any channel info. On a model fitted on plain arrays the channels are drawn as Target 0, Target 1, and so on; with a montage, the butterfly and the spectrum colour each trace by its sensor's position.
    • plot_joint and plot_psd_topomap draw topomaps, so they need sensor positions (MNE Raw targets, or set_montage). Without them they raise before MNE does, saying what is missing: the channel info, its positions, or sensors at all, since source regions do not lie on a head.

    Common controls

    • The y-axis / colorbar is shown in coefficient units — σ_EEG/σ_x under standardization, an appropriate label otherwise — never µV. The modality name comes from the channel types in the info (EEG, MEG, sEEG, ...); target when there is no info, the types are mixed, or they are misc (source-space parcels).
    • The MNE N_ave tag is stripped: a TRF kernel is a regression coefficient, not an average of trials.
    • x_units="ms"|"s" sets the time axis.
    • title overrides the default ("<subject>-<stimulus>" in a subject view, else the stimulus).
    • subfeature chooses what a multi-column feature (d>1) contributes, since an Evoked holds one value per channel and delay:
    • "mean" (default) averages the sub-features — the same reduction plot_average shows on its top panel;
    • an int picks that column;
    • None returns one figure per sub-feature (and save_path is suffixed _sub0, _sub1, …).

    It is ignored for a scalar feature.

    plot and plot_joint additionally take grid, mean, std, sem (default grid=mean=std=True) to overlay a black channel-mean line with a shaded band on top of MNE's per-channel traces. plot_joint also shades the cohort's cluster result and forwards ts_args / topomap_args to MNE.

    model.plot("envelope", mean=True, std=True, x_units="ms")
model.plot_joint("spectrogram")                  # the sub-feature average
model.plot_joint("spectrogram", subfeature=2)    # just band 2
model.plot_image("spectrogram", subfeature=None) # one figure per band

    plot_average¶

    A montage-free butterfly + channel mean/std figure, drawn by the package itself, so it works on every owner, source space included.

    • A scalar feature (d==1) is one axis: thin per-channel traces, the bold channel-mean, and a ±channel-std band.
    • A multi-column feature (d>1) is two axes sharing the time axis: the butterfly of the sub-feature-averaged kernel on top, and a sub-features × time heatmap below (sub_labels names the rows).

    style="mne" (the default) draws the top axis with mne.Evoked.plot when a montage is available and falls back to the native drawing when it is not; style="native" opts out. What is plotted does not change, only the rendering.

    channel_reduce picks how the bottom panel collapses its channel axis — not its sub-features, which are the rows, and not the top panel:

    • "mean" (default): the signed average, so polarity is preserved. Drawn on a diverging scale centred at zero.
    • "gfp": the RMS. Reach for it when the response is dipolar — positive over some sensors, negative over others — where the signed mean cancels a real effect toward zero. It is non-negative, so it is drawn on a sequential scale anchored at zero, and it discards the sign.

    At the cohort level, once a cluster test has run, significant delays are shaded green (positive) / red (negative) and the heatmap dims its non-significant cells. alpha_level sets the cutoff and min_sig_channels how many channels must reach it for a delay to count (an int counts channels, a float in (0, 1) is a fraction of them), each sign on its own: a delay where enough channels are significant both ways -- a dipolar topography, such as an auditory response reversing under a mastoid reference -- is shaded green over red, half the height each. show_stats=False opts out.

    model.plot_average("envelope")
group.plot_average("envelope", show_stats=True, min_sig_channels=0.25)
group.plot_average("spectrogram", channel_reduce="gfp",
                   sub_labels=["0.5–2", "2–4", "4–8", "8–16", "16–32"])

    plot_contrast¶

    The difference between two features of one model, spec_a - spec_b. This is the picture behind permutation_test_contrast_features / tfce_contrast_features: those return a p-value for the difference, and this draws the difference itself.

    Both kernels are partial coefficients from the same design and solve, so they share an regularization, a normalization, the folds and the sample count, and each is estimated controlling for the other — which is what subtracting two separately fitted models would not give you. The canonical use is a pair of condition-coded versions of one regressor (attended vs unattended, target vs distractor) entered as two features.

    • kind="average" (default) gives the plot_average figure, montage-free.
    • kind="joint" gives the plot_joint figure — butterfly plus topographies at the peaks — of the sub-feature-averaged difference. Needs a montage.

    Shading comes from the stored result for that ordered pair; testing (a, b) and plotting (b, a) warns rather than reusing the result with a flipped sign, which would only be exact for a two-sided test.

    The two features must share a delay window and a sub-feature count (checked). Whether their difference means anything is yours to judge: two condition-coded envelopes are weights against the same kind of regressor, an envelope minus a spectrogram is not.

    group.tfce_contrast_features("attended", "unattended")
group.plot_contrast("attended", "unattended", kind="joint")
model.plot_contrast("attended", "unattended")     # one participant, unshaded

    plot_features / plot_feature¶

    The summary figure: one column per feature, three stacked rows sharing a delay axis.

    1. the butterfly of the kernel (averaged over sub-features), with significant delay intervals shaded;
    2. for a scalar feature the channels × time image with the non-significant region greyed out; for a multi-column one a sub-features × time heatmap of the channel-collapsed coefficient (channel_reduce, as in plot_average). A black curve on a twin axis traces how many channels are significant at each delay;
    3. a topomap at the peak of the significant span (the GFP peak when nothing is significant), with the significant sensors marked.

    specs=None plots every feature; pass a list to choose. ylims, vlim_topo, topo_times and sub_labels accept either one value for all columns or a {spec: value} dict.

    Needs a montage, for the topomap of row 3. Significance is read from the cohort's stored cluster test, so the same call renders unshaded for a lone TRFModel or a single subject.

    group.plot_features()                               # every feature, side by side
group.plot_features(["envelope"], min_sig_channels=0.25)
group.plot_feature("spectrogram", sub_labels=["0.5–2", "2–4", "4–8", "8–16", "16–32"])
model.plot_feature("envelope")                      # one participant, no shading
group("s01").plot_features()

    plot_metric_topomap¶

    The per-channel held-out metric as an mne topomap; the metric name (e.g. Pearson) labels the colorbar and the title. Needs a montage.

    model.plot_metric_topomap()
group("s01").plot_metric_topomap()     # title prefixed with the subject id

    plot_source_butterfly / to_stc¶

    Source space. Neither takes a sensor montage: both need region centroids, set with TRFData.set_source_positions.

    plot_source_butterfly is the source-space counterpart of the spatially coloured butterfly MNE draws for sensors. MNE's version interpolates onto a head surface, which parcel centroids do not lie on, so this one keeps the part that carries the meaning — where a trace comes from, readable off its colour (red = right, green = anterior, blue = left) — and drops the topography. A panel on the right places each region as a dot in a top-down head outline, so a colour in the butterfly can be traced back to a place. gfp=True shades the global field power under the traces, show_stats shades significant delay intervals exactly as plot_average does, and a multi-column feature is averaged over its sub-features.

    to_stc draws nothing. It paints one feature's kernel back onto a cortical surface and returns an mne.SourceEstimate, whose own .plot() does the 3D rendering. It needs the parcellation the channels are named after (labels) and the source space defining the vertices (src); subfeature picks the column, since an Evoked — and so an stc — holds one value per vertex and delay. To go straight from an Evoked you already have, use evoked_to_stc instead.

    group.plot_source_butterfly("envelope")
stc = model.to_stc("envelope", labels=labels, src=src)
stc.plot(subjects_dir=subjects_dir, hemi="both")

    plot_bootstrap¶

    Cohort only. Compares the per-subject bootstrap metric distributions side by side, as violins (kind="violin") or boxes, with the confidence interval ci marked — the figure that shows whether one participant carries the cohort's effect.

    Requires the subjects to have been fitted with bootstrap=True. subject_ids selects a subset, sort=True orders them by score, and channel_reduce ("mean", "median", "max" or a channel index — a different vocabulary from plot_average's) collapses each subject's channels to one number.

    group.plot_bootstrap()
group.plot_bootstrap(kind="box", ci=95, sort=True)

    validation_plot¶

    Model only. Renders the gridsearchCV figure: the aggregated metric against the regularization grid with the selected value marked, plus one panel per feature stacking the channel-averaged TRFs over that grid. After a banded search the top panel carries one curve per band ratio over a shared λ axis, with the winning ratio drawn heavier and the selected per-band λ values in the title.

    gridsearchCV records its data on every run regardless of its own validation_plot flag, so the figure can be re-rendered any time.

    model.gridsearchCV(regularization_grid=np.logspace(-2, 6, 20), validation_plot=False)
model.validation_plot(save_path="validation.png")

    See the whole workflow rendered end to end in the Tutorials and Examples, and the full method signatures in the plotting API.
